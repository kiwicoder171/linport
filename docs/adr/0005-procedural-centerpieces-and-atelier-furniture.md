# 0005: Procedural 3D Centerpieces and Atelier Staging

We decided to build the museum's centerpiece sculptures and Atelier furniture (drafting easels, studio desks, benches, spotlight tracks) as code-only procedural Three.js models rather than relying on bloated external GLTF asset packs. This guarantees zero external model download latency, pure mathematical geometry sharpness, customizable materials that react dynamically to scene lighting, and total architectural coherence.
